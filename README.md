# 学生手册本地问答工具

把学生手册做成了一个本地知识库。输入“对处分有异议，如何申诉？”这样的问题，就能看到回答和对应的原文条款。

## 为什么做这个项目

学生手册内容比较多，查一项规定经常要翻目录、搜关键词。我想把自己了解的 RAG 原理用到这份资料上，让查询方便一些，也能随时回到原文核对。

这次的代码编写和本地部署主要借助 Codex 完成。我提出需求、提供手册，运行后参与试用并反馈问题。目前工具已经在我的 Windows 电脑上跑通。

## 可以做什么

- 导入 DOCX 正文和表格，保留章节、条款等出处信息。
- 用自然语言提问，查看模型根据检索内容给出的回答。
- 展开引用原文，核对文件名、章节和正文位置，也可以只检索原文。
- 资料不足时给出提示，模型和依赖准备好后可离线使用。

界面有“查询并回答”和“只查看原文”两个入口，可以查奖学金申请条件、处分申诉、转专业和公寓管理等内容。

## 实现方式

```text
DOCX 手册
  → 提取正文、表格和章节信息
  → 切分原文片段并保留出处
  → 本地向量模型建立索引
  → 语义检索 + 中文双字关键词检索
  → 合并检索排名
  → 本地问答模型生成回答
  → 展示回答和引用原文
```

程序使用 Python 和 NumPy 处理资料与索引，通过 Ollama 调用本地模型，界面用 HTML/CSS/JavaScript 编写。向量模型是 `qwen3-embedding:0.6b`，问答模型是 `qwen3:4b-instruct-2507-q4_K_M`。

检索时结合语义向量和中文双字关键词，再合并两种检索的排名。片段与向量分别保存在本地 JSON 和 NumPy 文件中。

## 导入和测试

这份手册共导入 45 个章节、30 个 Word 表格。另有两张图片表格，经原图核对后转录补入，最终建立了 939 个检索片段。

搭建时，Codex 做了四项问答检查和五项检索检查，核对了正文提取结果，也测试过停止、重新启动和桌面路径运行。测试覆盖了奖学金、申诉等问题，以及资料不足时的提示，具体结果见 [验证记录](docs/验证记录.md)。

## 如何运行

环境准备和启动步骤见 [运行说明](运行说明.md)。需要 Python、NumPy、Ollama 和 DOCX 资料，首次使用需要下载模型。

仓库提供源码和说明，手册原件、模型、运行环境及本地索引保留在自己的电脑上。

## 使用时需要注意

回答依据导入的手册版本，具体规定需要核对学校的新通知。模型也可能答错或漏掉条件，可以展开引用查看原文。Word 页码会随排版变化，所以这里用章节、条款和“正文块”定位。

目前支持可提取文字的 DOCX，扫描件、图片文字、PDF 和旧版 DOC 需要先处理。解析器对这份学生手册做过适配，换用其他文件时需要检查章节和文本提取结果。
